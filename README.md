# Engenharia de Dados

Repositório dedicado à organização dos meus estudos e conhecimentos em **Engenharia de Dados**.

Este espaço reúne anotações, resumos e materiais desenvolvidos ao longo da minha **Pós-graduação em Engenharia de Dados**, com o objetivo de consolidar conhecimentos técnicos e manter uma base de consulta para aprendizado contínuo.
