# Engenharia de dados — Anotações

Repositório criado para consolidar meus estudos e conhecimentos adquiridos durante a **Pós-graduação em Engenharia de Dados**.

O objetivo é organizar conceitos, ferramentas, arquiteturas e práticas relacionadas à Engenharia de Dados, além de registrar aprendizados e referências para consulta futura.

Atualmente, está presente nesta pasta no repositório um arquivo com um resumo básico que utilizo como direcionador para entender as conexões realizadas entre as subáreas da engenharia de dados, desde arquitetura a segurança e cultura DevOps.
